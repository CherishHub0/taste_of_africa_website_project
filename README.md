# Taste of Africa

A multi-page website about African food, built for Advanced frontend dev.

Live site: https://cherishhub0.github.io/taste_of_africa_website_project/

## Pages
- Home (hero, featured dishes, regions, food trends)
- Recipes (filter by region) and 5 dish pages: Jollof Rice, Chicken Tagine, Injera, Bunny Chow, Isombe
- 4 region pages: West, North, East and Southern Africa
- About and Contact

## Features
- Recipe filter by region
- Favorites saved with localStorage
- Ingredient servings scaler
- Dark / light mode
- Contact form check (message must be over 20 characters)
- Newsletter signup in the footer

## Built with
HTML, CSS and JavaScript. Fonts from Google Fonts.
